The taskThe motor is too weak to lift the pendulum directly, so the agent has to learn to swing it back and forth to build momentum, then catch it upright.
The agentA small neural network (64-64 tanh) estimates the value of each torque level (9 or 11 options), and the agent picks the best one. It was trained with experience replay and a target network.
The resultsUpright control reached about 80% under default gravity. For free-fall and anti-gravity, targeted refinement raised it to about 85%, from 24% and 50%.
